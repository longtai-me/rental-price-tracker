# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue for vulnerabilities.

Report security issues privately to the project maintainer through the repository owner's preferred contact channel. Include:

- Affected route, feature, or file
- Steps to reproduce
- Impact and severity
- Suggested fix, if available

## Sensitive Data

This project may process rental addresses, uploaded rental contracts, admin access logs, and IP addresses. Treat all of them as sensitive. Do not commit production data, logs, secrets, or uploaded files to the repository.

## Supported Versions

Security fixes are handled on the default branch.
